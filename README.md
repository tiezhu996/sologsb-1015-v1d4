# 古诗格律校勘台

面向诗词编辑与校勘人员的浏览器工作台。可逐字标注平仄、韵组和停顿，建立对仗关系，记录每条判断依据，并对多个异文版本进行并排定位。

## 功能

- 录入诗句并按五言、七言格律模板逐字对照。
- 平仄、停顿、韵组、判断依据和批注可逐字维护。
- 自动提示出律位置、一三五位置可接受变体、待标字和重复用韵。
- 建立句间对仗关系，记录关系说明。
- 多版本独立校勘，字符级并排比较与上下处差异定位。
- **新见刻本的整段批注先进入“待裁决批次”，与当前字格逐字对照，不直接覆盖手定。**
- **手工判定与建议冲突时两版并存：采纳才写入字格并保留来源（刻本/批次/建议号/依据/时间），手定历史不丢。**
- **正文增删后按字做 LCS 对账：旧标注随原字迁移到新字位（稳定字位 id 不变），改字/删字对不上的摘为“失效标注”待重算，新增字留空待标，受影响句的对仗转待复核。**
- **批次可中断并从上次字位继续；旧版（v1）数据升级时按原字锚定，既有标注绝不串到别字。**
- **字格角标、异文对照页与 Markdown 导出共用同一份裁决进度。**
- 文档级撤销/重做、键盘巡校和浏览器本地持久化。
- 导出包含字音标注、来源、检查记录、批次裁决进度、失效标注与版本来源的 Markdown 校对稿。
- 针对平板和桌面优化布局，支持长时编辑。

## 版本裁决工作流

1. 在「版本裁决」页录入新见刻本名称、来源与异文，点击“生成逐字对照建议”。
   - 平仄由内置字书自动拟，韵组／停顿／依据／批注可在提交前逐字补加、改值或删除。
   - 此阶段只生成草稿，**字格一个字都不会改**。
2. “提交为待裁决批次”后，建议按**稳定字位**逐字挂到当前正文，并在字格上显示待裁角标。
3. 逐字裁决：每条建议展示“手定现值 → 刻本建议”。
   - **采纳**：写入字格，标注来源变为该刻本，并在来源链保留手定旧版与建议号。
   - **否决**：仅记录存弃结论，字格不动。
   - **保留两版**（冲突时）：字格维持手定，建议以“并存”留档，可随时撤回再裁。
   - 每裁完一字自动跳到下一待裁字位；“中断”后批次保留位置，再次进入即**从上次位置继续**。
4. 正文增删后自动对账：
   - 同字随原字迁移（字位 id 不变）；改字、删字对不上原字的旧标注进入“失效标注”，**只允许重挂到仍是原字的位置**；新增字待标；受影响句上的对仗转“待复核”。
   - 锚定字位已不存在的待裁建议自动作废。
5. 字格待裁角标、异文并排比较页的“裁”标记、导出 Markdown 的“版本建议裁决进度/失效标注/对仗”章节，读的是同一份状态。

## 键盘操作

| 快捷键 | 操作 |
| --- | --- |
| `↑ / ↓ / ← / →` | 在字格中移动 |
| `1 / 2 / 3` | 标为平 / 仄 / 中 |
| `R` | 循环切换韵组 |
| `Space` | 切换停顿标记 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` | 重做 |
| `Ctrl/Cmd + S` | 本地保存提示 |

## Docker

容器内由 nginx 监听端口 `80`，源码不硬编码宿主端口。

```bash
docker build -t classical-poetry-meter-editor .
docker run --rm -p 10015:80 classical-poetry-meter-editor
```

宿主端口 `10015` 仅用于本地运行示例，实际端口由根编排文件统一管理。
